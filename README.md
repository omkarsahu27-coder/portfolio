# Omkar Sahu | Personal Portfolio

A lightning-fast, accessible, and responsive personal portfolio website built to showcase my software development projects, skills, and AI tools. 

**Live Site:** [portfolio-omkar-sahu.vercel.app](https://portfolio-omkar-sahu.vercel.app)

## 🚀 Tech Stack
* **Framework:** [Astro](https://astro.build/)
* **Styling:** CSS / Tailwind CSS
* **Deployment:** Vercel
* **Languages:** JavaScript, HTML

## ✨ Features
* **High Performance:** Built with Astro's zero-JS frontend architecture for maximum speed and SEO.
* **Project Showcase:** Highlights my full-stack and AI projects, including LecScribe, dynamic web platforms, and custom AI tools.
* **Fully Responsive:** Optimized for mobile, tablet, and desktop views.
* **Accessible:** Clean, semantic HTML structure.

## Setup & Scripts

- `npm install` - Install dependencies
- `npm run dev` - Start local development server at `localhost:4321`
- `npm run build` - Build the production site to `./dist/`
- `npm run preview` - Preview the production build locally
- `npm run format` - Format code using Prettier

## Content Management

Content is driven by Astro Content Collections in `src/content/`. 
Add or edit markdown files inside `projects/`, `education/`, and `skills/`.

## Deployment

Connected to Vercel. Pushing to the `main` branch will automatically trigger a production build.
